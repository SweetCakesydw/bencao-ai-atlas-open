# 公开内容边界

本项目采用“公开体验、公开说明、核心闭源”的发布方式。

## 可公开

- 产品介绍、功能清单与公开路线图。
- 不包含生产参数的高层架构图。
- 人工审核的产品截图和演示视频。
- 不连接生产 API 的模拟请求与模拟响应。
- 隐私、安全、BYOK 和匿名体验的设计原则。

## 须审核后才可公开

- 通用且不含业务规则的 UI 组件。
- 脱离生产数据与端点的简化演示代码。
- 脱敏后的输出 Schema 和虚构数据样例。
- 不含内部路径、配置和日志的测试摘要。

## 禁止公开

- 生产网站完整源码及其 Git 历史。
- Supabase Edge Functions、数据库迁移、RLS 策略和运维脚本。
- 提示词、Skill、召回逻辑、评分权重、修复和校验规则。
- 完整药材语料、私有数据集与数据导入结果。
- API Key、Service Role Key、Token、Cookie、密码或生产环境变量。
- 内部交接文档、完整回归测试、故障日志与安全实现细节。

## 公开流程

1. 所有公开内容从空白公开仓库中独立维护。
2. 不得将生产仓库设置为公开仓库的 Fork、Template 或上游镜像。
3. 不得复制生产仓库的 `.git` 目录或任何历史记录。
4. 新增文件在提交前必须进行密钥、内部路径、生产配置和受限数据检查。
5. 公开仓库不得自动同步生产仓库的全量内容。
