# 常见问题

## 这是完整的开源仓库吗？

不是。这是项目的公开体验与技术说明仓库。生产源码、私有数据、提示词、业务 Skill 和运维配置不在公开范围内。

## 为什么可以使用网站，却看不到完整源码？

线上体验与源码授权是两件不同的事。网站公开提供产品体验，核心数据、AI 编排与业务规则保留在私有服务端。

## 能否使用自己的 AI Key？

网站支持的具体模型与操作方式以线上模型配置面板为准。自有 Key 用于转移模型 Token 费用，不改变网站的 Skill、提示词和输出校验规则。

## 网站内容可以作为诊疗建议吗？

不可以。所有内容仅供文化展示、知识检索和技术交流，不构成医疗建议。

## 可以复制这个项目或用于商业项目吗？

除非具体文件标明了单独授权，否则公开可见不代表授予复制、改编、再发布或商业使用权。

## 如何反馈问题？

产品体验、文档或可访问性问题可通过 GitHub Issues 反馈。安全漏洞请不要在公开 Issue 中披露利用细节，请参考根目录的 `SECURITY.md`。
